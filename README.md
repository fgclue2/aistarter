# Open App Inventor Starter
> Replacement for MIT App Inventor's aiStarter

Open App Inventor Starter (aka gasoline) is a library that helps you connect app inventor to your PC.

Gasoline uses the **ADB Server**, instead of running ADB directly. This means that everything should work better, and also you could use this as an ADB protocol implementation.

Gasoline allows for **any** device or emulator to be used.

## How it works

It's just an HTTP server. In the original version, CORS is set to '*'. In this version that is fixed because it is not a good idea.
